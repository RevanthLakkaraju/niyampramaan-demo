# SPASHTA — Team X-CEPTION

Synthetic SIH26261 reference demonstration. Each browser receives its own temporary case, role sessions and manual 51-scene walkthrough. Different tabs in the same browser share that browser’s case. No AICTE integration or production approval is provided. Use supplied sample documents only.

Render: Python 3; build `pip install -r requirements.txt`; start `python server.py`; Free instance. Hosted environment binds to PORT. Records are temporary and reset on restart. Maximum 200 browser workspaces per service process.

The public demo accounts are institution.demo / Institution@26 and reviewer.demo / Review@26. Recording walkthrough handles role changes automatically. Next and Previous have no scene countdown.
